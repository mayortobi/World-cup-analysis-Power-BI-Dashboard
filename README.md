# World Cup Dashboard w/ Power  BI

![Dashboard Page 1](/Images/Project%20page%201.png)

## Introduction

The World Cup Analysis Dashboard is an interactive Power BI project designed to explore and visualize key performance indicators and historical trends across four FIFA World Cup tournaments. The dashboard transforms football data into meaningful insights,  Using a *real-world dataset of 2010 to 2022 world cup data set* (including teams, attendance, rounds, host country and year), providing an overview of tournament statistics, match outcomes, goal-scoring patterns, attendance trends, and team performances.

## Skills Showcased

-  **Data Transformation (ETL) with Power Query:** Cleaned, shaped and prepared the raw data for analysis by handling blanks, changing data types and creating new columns.
- **Implict Measured:** Formulated measured to derive key insight and KPIs like `Total Goals`, `Total Matches`, `Total Attendance` and `Total Penalty`.
-  **Core Chart:** Utilized **Column, Bar, Donut, Line** and **Area Charts** to compare Goals, Matches counts, Attendance trend, and Match results.
- **KPI Indicator & Tables:** Used **Cards** to display key metrics and **Tables** to provide granular, sortable data
- **Dashboard Design:** Designed an intuitive and visually appealling layout, exploring both common and uncommon chart types to best tell the data story.
- **Interactive Reporting:**
  - **Slicers:** To dynamically filter the report by year.
  - **Bookmarks:** To create a seamless navigation experience.

  ## Dashboard Overview

  ### Page 1: World Cup Analysis

  ![Dashboard Page 1](/Images/Project%20page%201.png)
 The World Cup Analysis Dashboard is an interactive Power BI report designed to analyze historical FIFA World Cup data across four tournaments. The dashboard explores annual goal-scoring trends, match result distributions, attendance patterns, host country comparisons, tournament stages, and team performances in home and away matches. Through interactive visualizations and key performance indicators (KPIs), it enables users to identify patterns, compare team contributions, and gain insights into the dynamics of World Cup competitions.

  ### Page 2: World Cup Goal Analysis

  ![Dashboard Page 2](/Images/Project%20page%202.png)  

  The World Cup Goal Analysis Dashboard is an interactive Power BI report designed to analyze FIFA World Cup match data, with a particular focus on goal distribution, penalty statistics, and team performance across four tournaments. It enables users to explore match-level information, compare home and away team performances, and examine penalty statistics across participating nations.

## Conclusion

The World Cup Analysis Dashboard demonstrates the value of data visualization in understanding football history and tournament performance. By bringing together goal statistics, match outcomes, attendance figures, tournament stages, and team-level comparisons, it provides a structured view of the factors that characterize World Cup competitions.
